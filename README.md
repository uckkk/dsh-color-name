# dsh-color-name · 颜色名称

纯 Node 实现，无网络、无外部服务。

## 安装

```bash
dsh plugin add dsh-color-name
```
安装后在 profile 的 `package.json` 的 `dsh.profile.bundles` 中加入 `"dsh-color-name"`。

## 安装

```bash
dsh plugin add github:uckkk/dsh-color-name
```

> 安装即在本机运行第三方代码，请自行审阅源码。
